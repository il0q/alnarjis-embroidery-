موقع النرجس للتطريز — النسخة المحسّنة

التحديث والنشر:
1. ارفع جميع محتويات هذا المجلد إلى جذر مستودع GitHub Pages الحالي.
2. تأكد من إبقاء الملفات sw.js وmanifest.webmanifest ومجلد assets بجانب صفحات HTML.
3. افتح الموقع مرة واحدة مع اتصال بالإنترنت لتفعيل التخزين المؤقت وتثبيت التطبيق إذا كان المتصفح يدعم ذلك.
4. بعد أي تحديث جديد، غيّر CACHE_NAME داخل sw.js حتى يحصل الزوار على نسخة جديدة.

ميزات هذه النسخة:
- نسخة فيديو أصغر لتقليل وقت التحميل.
- تطبيق ويب قابل للتثبيت ودعم صفحات أساسية عند انقطاع الاتصال بعد زيارتها.
- تنبيه واضح عند عدم الاتصال.
- حفظ مسودة الطلب مؤقتًا داخل sessionStorage لمدة تصل إلى 4 ساعات؛ لا تُحفظ ملفات الصور.
- رقم مرجعي قصير للطلب يظهر في النموذج والبريد وواتساب وصفحة التأكيد.
- مشغّل موحد لمؤشر التمرير وزر العودة للأعلى لتجنب تكرار السكربتات.
- تحسين أوصاف الصفحات ومعلومات المشاركة الاجتماعية وإمكانية الوصول.

ملاحظات:
- إرسال الطلب إلى البريد وفتح واتساب يحتاجان إلى اتصال بالإنترنت.
- التخزين المؤقت لا يحوّل الموقع إلى نظام إدارة طلبات؛ لا يوجد خادم تتبع للطلبات.
- الصورة المرفقة لا تُحفظ ضمن المسودة ويجب اختيارها مجددًا بعد تحديث الصفحة.
