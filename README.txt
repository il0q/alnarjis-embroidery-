النرجس للتطريز - النسخة المعدلة

التعديلات:
- توحيد الهوية البصرية بإدخال التركوازي الخاص بالشعار مع الإبقاء على العنابي والذهبي.
- إضافة زر واتساب عائم في جميع الصفحات.
- إضافة قسم "كيف تتم عملية الطلب؟" في الصفحة الرئيسية.
- إضافة دعوات واضحة للطلب والتواصل عبر واتساب.
- تحسين صفحة الطلب بإضافة خيار تواصل مباشر عبر واتساب.
- تحسين صفحة التواصل وإضافة زر انتقال مباشر إلى نموذج الطلب.
- تحسين صفحة تأكيد الطلب بإضافة زر واتساب.
- إصلاح تنسيق كلمة النرجس في نص صفحة التواصل.
- الحفاظ على الفيديو er.mp4 والشعار lo.png.

ملاحظة:
لم تتم إضافة صور معرض أعمال وهمية. عند توفير صور أعمال التطريز الحقيقية يمكن إضافتها كمعرض احترافي دون اختلاق محتوى.
